# v2.1.0 — CI整理と実VM境界の検証

2026-11-02

CIの起動を一本化し、MacのColimaとWindowsのWSL2で、ホストからVMを経由する実際の処理を確認するテストを追加しました。利用者向けのセットアップ・認証・Crew起動停止スクリプト、Dockerfile、導入ソフトのバージョンに変更はありません。既存環境の作り直しは不要です。

## 主な変更

- PRで変更に関係するOSだけを検証し、featureへのpushとの重複起動を解消。PR更新時は古い実行をキャンセルします。
- mainのCFD検証は、Ubuntu新規導入の統合テストかイメージ単体テストのどちらかを選び、同じCPUでの二重ビルドを解消しました。
- Macの実Colima Linux VMから、製品のDocker接続チェック、Ubuntu 24.04コンテナのCompose実行、日本語引数、双方向のファイル共有、UID、別コンテナでの永続化、終了コードを検証します。
- Windows x64の実WSL2 Ubuntu 24.04で、PowerShell 5.1／7からの引数・日本語パス・stdout／stderr・終了コードと、プロジェクト配置・LF正規化・秘密ファイル除外・再実行を検証します。
- Windows両CPUの制御、Linux両CPUのCLI・CFD、MacのCLI・launchdの既存検証は維持。ParaViewの依存ロック再調査は手動実行に限定しました。

## 検証結果と範囲

[PRのCI実行](https://github.com/TatsuyaKatayama/opencae-workshop2026-env/actions/runs/41318993262) で、ソース、Windows両CPU、実WSL2、Linux両CPUのバックエンド、Macホストと実Colima VMが成功しました。

MacのCIはQEMU／TCG＋9pです。製品のVZ／virtiofs、Mac上のCFD全体、個人認証・Finder操作の実機受け入れは残ります。Windowsの追加CIもx64の引数・配置境界に限定し、製品のrootfsインポートやsystemd＋Docker＋Crew全体、ARM64上の実WSL2を代替しません。

詳しい起動条件は [CI構成](../ci.md)、各実行の結果は [検証記録](../validation.md) を参照してください。配布対象は引き続きスクリプト・設定・資料のみで、ビルド済みイメージを公開しません。
