# v1.0.0 — Windows 版リリース

2026-11-01

Windows 11 の x64／ARM64 向けに、専用 WSL2 Ubuntu 24.04 の構築から AI エージェントの認証、Crew の起動・停止までを提供する初回リリースです。利用者による Windows 実機確認を完了しました。

## 主な機能

- `Setup.ps1` から専用 Ubuntu を新規作成。環境名・Linux ユーザー・保存先を指定でき、途中で停止した場合も同じ設定で再開できます。
- 共通 Bash コアで Docker Engine、Kiro CLI、Crew、OpenCode、Codex CLI を導入。Docker Desktop は使用しません。
- OpenFOAM v2606、ParaView 5.13.3 の CPU ヘッドレス描画と Python 後処理環境を含む CFD イメージを、事前セットアップ時にローカルビルドします。ビルド済みイメージは配布しません。ParaView は amd64 で OSMesa バイナリ、ARM64 でソースビルドを使用します。
- Crew のバックエンドとして Kiro CLI／Codex／OpenCode を選択し、同じ WSL ユーザーで認証します。Codex はデバイスコード認証に対応します。KAS は使用しません。
- Crew 稼働中の WSL 維持と、停止直後の再起動時のポート確認を改善しました。
- Windows の SHA256 検証、共有設定ファイルの改行処理、インストーラーの URL・ハッシュ固定を改善しました。

## Windows の操作

インストール先に次の CMD を配置し、PowerShell は `scripts` 配下にまとめます。

| ファイル | 操作 |
| --- | --- |
| `1_StartBackend.cmd` | バックエンドの選択・認証 |
| `2_StartCrew.cmd` | Crew を起動し、既定ブラウザーで開く |
| `3_StopCrew.cmd` | Crew を停止 |
| `9_Allclean.cmd` | 専用 WSL と関連設定を削除 |

Allclean は対象・実行コマンド・データ消失の警告を表示し、`DELETE` と正確に入力した場合だけ削除します。WSL 内のファイル、認証情報、Docker イメージ、計算結果は失われます。通常の終了には `3_StopCrew.cmd` を使用してください。

## 既存環境の更新

取得元リポジトリのローカル変更を整理したうえで、PowerShell から実行します。環境名と保存先は実際の構築時の値に置き換えてください。

```powershell
git switch main
git pull --ff-only
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup\windows\UpdateLaunchers.ps1 `
  -DistroName opencae-workshop2026 -InstallLocation C:\wsl_img\opencae-workshop2026
```

起動ファイルと Crew の補助スクリプトを更新します。WSL の作り直しや CFD イメージの再ビルドは不要です。新規導入は [README](../../README.md)、詳細は [Windows 手順](../windows.md) を参照してください。

## 検証範囲と今後の予定

- Windows x64／ARM64 の PowerShell 5.1／7 制御テスト、Linux ソース検査、両 CPU のバックエンドバイナリ導入・ACP 初期応答が CI で成功しています。
- Ubuntu 両 CPU の CFD ビルド・計算・描画・動画生成の検証履歴は [検証記録](../validation.md) を参照してください。
- Windows 実機確認の完了は利用者の報告に基づきます。CI の Windows 制御テストは WSL 操作や認証をモックで確認しています。
- Allclean の制御・キャンセル・自己削除後の CMD 終了はテスト済みですが、実際の WSL 全削除は開発機で実行していません。
- Proxy 対応はプレビューです。macOS 対応は今後の予定です。
